# Ziak United Sponsor List Preparation

เตรียมรายชื่อและติดตามการทักสปอนเซอร์ของช่อง Ziak United

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `brands.json` | รายชื่อ 20 แบรนด์แรก แยกตามสัปดาห์ พร้อมช่องทางติดต่อและมุมนำเสนอ |
| `outreach-tracker.csv` | รายชื่อชุดเดียวกันสำหรับเปิดใน Excel หรือ Google Sheets |
| `outreach-tracker.html` | ซอร์สของหน้าติดตามการทักบน claude.ai |

หน้าที่ใช้งานจริง

- ไฟล์ติดตามการทัก: https://claude.ai/artifact/J1BTjxCputB68k4yFFwTW1
- Media kit: https://claude.ai/artifact/3fV6aVqrWmBmJxb4jSDKEQ
- คู่มือเตรียมตัวและร่างอีเมลรายแบรนด์: https://claude.ai/artifact/7G7kdZczcLxWEvAYQ9fdPx

สถานะการทักของจริงอยู่ในหน้าติดตามบน claude.ai ไฟล์ในนี้คือรายชื่อตั้งต้น
